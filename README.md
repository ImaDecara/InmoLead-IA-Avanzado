# InmoLead IA - AI Automation Avanzado

Repositorio destinado al desarrollo progresivo del proyecto **InmoLead IA** dentro del curso de **AI Automation Avanzado**.

El objetivo del repositorio es almacenar, documentar y versionar las distintas entregas realizadas durante el curso, manteniendo un único proyecto que irá evolucionando módulo a módulo.

---

## 📌 Descripción del proyecto

**InmoLead IA** es un sistema de automatización orientado a una inmobiliaria.

El objetivo general es construir un asistente inteligente capaz de recibir consultas de potenciales clientes, interpretar sus necesidades y ejecutar acciones utilizando herramientas externas.

El sistema se desarrolla principalmente utilizando **n8n** como plataforma de automatización y agentes de inteligencia artificial como motor de razonamiento.

---

## 🎯 Objetivo del repositorio

Este repositorio será utilizado para:

- Almacenar los workflows desarrollados en n8n.
- Versionar cada checkpoint y entrega del curso.
- Documentar la evolución del sistema.
- Registrar las integraciones utilizadas.
- Mantener evidencia de la arquitectura implementada.
- Centralizar los archivos necesarios para la entrega final.

Cada módulo del curso extenderá las capacidades implementadas anteriormente, evitando crear proyectos independientes.
